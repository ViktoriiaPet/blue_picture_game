# The Missing Painting 🖼️

**The Missing Painting** is an interactive detective game built with React, TypeScript, and Vite.

A valuable painting has disappeared from a private art gallery. Three people may know something about the case, but not everyone is telling the truth.

Explore the gallery, talk to the suspects, collect clues, and use your detective skills to find out what happened.

🎮 **Play the game:** [The Missing Painting](https://viktoriiapet.github.io/blue_picture_game/)


## ✨ Features

- **Interactive story** — investigate a missing painting in an art gallery.
- **Dialogue system** — talk to three suspects and discover new information.
- **Clue collection** — explore different rooms and find useful evidence.
- **Multiple locations** — move around the gallery and investigate other rooms.
- **Suspect selection** — choose who you think is responsible.
- **Final scene** — discover the result of your investigation.

## 🚀 How to Run the Project Locally

### Requirements

You need to have [Node.js](https://nodejs.org/) and npm installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ViktoriiaPet/blue_picture_game.git
   ```

2. Open the project folder:

   ```bash
   cd blue_picture_game/blue_picture_game
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173/`.

### Build the Project

To create a production build, run:

```bash
npm run build
```

To test the production build locally, run:

```bash
npm run preview
```

## 🕵️ How to Play

1. **Read the introduction.** Learn about the missing painting and the rules of the investigation.
2. **Talk to the suspects.** Speak with Clara, Daniel, and Sofia. Listen carefully to their answers.
3. **Explore the rooms.** Look for clues and pay attention to objects around you.
4. **Collect evidence.** Find useful information and use it to unlock new dialogue.
5. **Compare the clues.** Check what each suspect says and look for details that do not match.
6. **Find the painting.** Continue the investigation until you discover where it is hidden.
7. **Choose a suspect.** Use the evidence to decide who is responsible for the disappearance.

**Tip:** Do not rush to make a decision. One clue may not be enough to understand the whole story.
